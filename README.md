# AI Resume Analyzer

A web app that analyzes a resume against a job description and gives an ATS-style score, matched skills, missing skills, and suggestions for improvement.

## Features

- Upload a PDF resume
- Paste a job description
- Generate an ATS score
- Identify matching and missing skills
- Get resume improvement suggestions
- Simple React frontend with a FastAPI backend

## Tech Stack

- React + Vite
- Tailwind CSS
- FastAPI
- Python
- Google Gemini
- pdfplumber
